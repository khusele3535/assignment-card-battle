# ✍️ UX Writing Audit (Microcopy Regulation)

Тоглоомын систем тоглогчтой харилцах бүх String текстийг хэрэглэгч төвтэй, ойлгомжтой, урам зориг өгөхүйц болгох үүднээс хийсэн аудитын тайлан.


| Байршил (Context) | Хуучин текст (System-Oriented) | Шинэчилсэн текст (User-Oriented) | Сайжруулсан шалтгаан (UX Logic) |
| :--- | :--- | :--- | :--- |
| **Main Menu** | Start Game | ⚔️ START NEW BATTLE | Зүгээр нэг тоглоом эхлүүлэх биш, тулааны уур амьсгалыг шууд мэдрүүлнэ. |
| **Error Screen** | No Mana! | ⚠️ Not enough Mana! Choose another card. | Тоглогчийг буруутгах биш, дараагийн хийх алхмыг (өөр карт сонгох) эелдэг зааж өгсөн. |
| **Battle State** | Player Turn | --- YOUR TURN --- | Ээлж солигдсоныг олон тэмдэгтээр тусгаарлаж, анхаарлыг шууд татна. |
| **Card Action** | You played Fireball | 🔥 Fireball! Dealt 9 damage. | Үйлдэл болон үр дүнг эможи болон амьд үгээр илэрхийлж, амжилтын мэдрэмж өгнө. |
| **Win Screen** | You Win | 🏆 VICTORY! You defeated the Boss! | Тоглогчийн хичээл зүтгэлийг үнэлж, урамшуулах өнгө аястай. |
| **Lose Screen** | Game Over | 💀 DEFEAT. Try a different strategy! | Тоглоом дууссаныг зарлаад зогсохгүй, дахин оролдох сэдэл (өөр стратеги) төрүүлнэ. |
