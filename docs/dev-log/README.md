# 📚 Development Log & Reflection

### 📆 Долоо хоног 1: Төлөвлөлт ба Дизайн (Design Phase)
*   **Хийсэн ажил:** Төслийн хавтасны бүтцийг стандартын дагуу үүсгэж, `src` болон `tests` хавтасны тохиргоог хийлээ. Тоглоомын гол зорилтот хэрэглэгчид болох Тулгаа, Ану нарын персонаг тодорхойлов. Figma дээр 80x24 консол харьцаатай Monospace фонт бүхий 5 дэлгэцийн wireframe-ийг зурж дуусгалаа.
*   **Бэрхшээл ба Шийдэл:** Консол тоглоомд wireframe-ийг хэрхэн хэрэглэгчид таатай зурах аргаа олохгүй байсан ч Roboto Mono фонт ашиглан ASCII хүрээг Figma дээр бодитоор буулгаж шийдэв.

### 📆 Долоо хоног 2: Суурь Код ба Логик (Core Implementation)
*   **Хийсэн ажил:** OOP-ийн үндсэн ойлголтуудыг ашиглан `Card` (abstract) класс болон түүнийг залгамжлах `AttackCard`, `HealCard`, `BuffCard` классуудыг үүсгэв. `Player` классаас `HumanPlayer` болон `AIPlayer`-ийг удамшуулан turn-based тоглоомын гол гогцоог (Game Loop) амжилттай угсарлаа.
*   **Бэрхшээл ба Шийдэл:** `InputReader` дээр хэрэглэгч тооноос өөр тэмдэгт оруулахад программ шууд гацаж байв. Үүнийг `try-catch` болон `sc.nextLine()` ашиглан буруу оролтыг цэвэрлэдэг болгон зассан.

### 📆 Долоо хоног 3: Төгсгөл ба UX Сайжруулалт (Polish & UX Phase)
*   **Хийсэн ажил:** `CreatureCard` картыг нэмж, тоглоомын төлөвийг хадгалах `GameSaver` (File I/O) функцийг нэгтгэв. 3 бодит хэрэглэгч дээр тест хийж, мана хүрэхгүй үед шидэгдэх `InsufficientManaException` алдааг тоглогчид хохиролгүйгээр (дахин карт сонгох) барьдаг болголоо. Хэлний сонголтыг (MN/EN) `Messages` классаар удирдав.
*   **Төгсгөлийн дүгнэлт:** Энэхүү бие даалтаар цэвэр код бичих нь ажлын ердөө тал хувь, нөгөө тал нь хэрэглэгчийн сэтгэл зүйг ойлгож, тэдэнд зориулж UI/UX дизайныг боловсруулах явдал гэдгийг бодитоор ойлголоо.
