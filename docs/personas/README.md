# 👥 Target Personas

Энэхүү карт тулааны тоглоомын хэрэглэгчийн интерфейс (UI) болон текстийн өнгө аясыг (UX Writing) дараах хоёр өөр хэрэглэгчийн бүлэгт зориулан зохиосон.

## Персона 1: Стратегич Тулгаа (The Hardcore Tactician)
*   **Нас / Мэргэжил:** 21 настай, Мэдээллийн Технологийн оюутан.
*   **Тоглоомын туршлага:** *Hearthstone* болон *Slay the Spire* тоглоомуудыг олон зуун цаг тоглосон.
*   **Хэрэгцээ ба Зан төлөв:**
    *   Тоглоомын тоон үзүүлэлтүүд (HP, Мана, Damage, Heal) маш нарийн, тодорхой харагдах ёстой.
    *   Консол дэлгэцийн бүтэц эмх замбараагүй байвал тооцоолол хийхэд саад болдог тул дургүйцдэг.
    *   Ээлж бүрийн үйлдлийг хянах цэвэрхэн тулааны түүх (Battle Log) шаардлагатай.
*   **Дизайн шийдэл:** Түүнд зориулж `ConsoleRenderer` дээр тэмдэгтээр илэрхийлсэн HP Bar болон мананы үзүүлэлтийг тоон утгатай нь хамт байнга дээд, доод хэсэгт тогтмол байршуулсан.

## Персона 2: Амрагч Ану (The Casual Story-Seeker)
*   **Нас / Мэргэжил:** 19 настай, График Дизайны оюутан.
*   **Тоглоомын туршлага:** Гар утасны энгийн тоглоомууд тоглодог, картны нарийн дүрэм сайн мэдэхгүй.
*   **Хэрэгцээ ба Зан төлөв:**
    *   Хичээлийн завсарлагаар 5-10 минут тоглож алжаалаа тайлах зорилготой.
    *   Хэт хүйтэн, робот шиг системтэй текстээс залхдаг. Сонирхолтой нэршил, ASCII дүрслэлд дуртай.
    *   Буруу товч дарах эсвэл мана хүрэхгүй үед тоглоом шууд гацах биш, эелдэг зааварчилгаа харахыг хүсдэг.
*   **Дизайн шийдэл:** Түүнд зориулж карт бүрийг "Strike", "Fireball" гэх мэт уран зөгнөлт нэрээр нэрлэж, мана дутах үед `InsufficientManaException` барин найрсаг мессеж харуулдаг болгосон.
