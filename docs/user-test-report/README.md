# 🧪 User Testing Report (3 Participants)

Хөгжүүлэлтийн явцад 3 бодит хэрэглэгчийг ажиглаж, тоглоомын интерфейс болон логикт дараах сайжруулалтыг хийлээ.

### 👤 Тестэр 1: Билгүүн (21 настай, МТ-ийн оюутан — Тулгаа персонаг төлөөлнө)
*   **Ажиглалт:** Эхний ээлжинд мана нь 1 байхад 3 мананы өртөгтэй "Fireball" карт гаргахыг оролдсон. Систем шууд ээлжийг нь алгасуулсанд дургүйцэв.
*   **Санал хүсэлт:** "Мана хүрэхгүй бол ээлж алгасах биш, өөр карт сонгох боломж олгох хэрэгтэй."
*   **Хийсэн сайжруулалт:** `HumanPlayer` дотор `try-catch` ашиглан алдааг барьж, мана хүрэхгүй бол ээлжийг алгасахгүйгээр дахин карт сонгох гогцоо (loop) нэмсэн.

### 👤 Тестэр 2: Намуун (19 настай, Дизайны оюутан — Ану персонаг төлөөлнө)
*   **Ажиглалт:** Карт сонгох дэлгэц гарч ирэхэд яг ямар тоо дарахаа мэдэхгүй 10 гаруй секунд эргэлзэж зогссон.
*   **Санал хүсэлт:** "0 гэж дараад ээлж алгасаж болдог гэдгийг заавар дээр илүү тод харуулах хэрэгтэй."
*   **Хийсэн сайжруулалт:** `ConsoleRenderer.renderHand` дотор `0. Skip Turn / Ээлжээ алгасах` гэсэн мөрийг жагсаалтын төгсгөлд маш тодорхой шинээр хэвлэдэг болгов.

### 👤 Тестэр 3: Анар (15 настай, Дунд сургуулийн сурагч — Casual Player)
*   **Ажиглалт:** Тоглоомыг шинээр эхлүүлэх үед цэвэрхэн ажиллаж байсан ч карт тоглуулах үед хэт хурдан бичигдээд өнгөрч байв.
*   **Санал хүсэлт:** "Карт гаргахад ямар нэг эффект эсвэл түр зогсолт байвал гоё харагдана."
*   **Хийсэн сайжруулалт:** `ConsoleRenderer.animateEffect` дотор `Thread.sleep(400)` ашиглан карт тоглогдох үед "BOOM!" болон "GLOW!" эффектийг түр зогсолттой харуулж, үйлдлийг илүү амьд болгосон.
